# Phishing-Email-Analysis-Report
This report documents a phishing email investigation, focusing on email header analysis, content inspection, and identification of malicious intent and deceptive tactics. The findings were compiled using best practices in email forensics and cybersecurity awareness.

This repository contains a detailed forensic analysis of a real-world phishing email, including step-by-step breakdowns of how the sender was identified, how the email impersonated a trusted brand, and how malicious intent was concealed using deceptive encoding and link redirection.

## 🔍 About This Project

The goal of this project was to analyze a phishing email sample using industry-standard practices in email header inspection, URL decoding, and content dissection. The purpose is to raise awareness and demonstrate technical capability in identifying, documenting, and mitigating social engineering threats.

---

## 🛠️ Key Skills Demonstrated

- Email header analysis
- Identification of spoofed sender domains
- URL decoding and redirection tracing
- Detection of base64-encoded malicious content
- Identification of impersonated branding elements
- Extraction of hidden URLs (including social media profiling links)
- Safe preview of phishing landing pages

## 📄 Report Summary

The full analysis is documented in [Phishing Email Analysis Report]([https://github.com/shadowphoeniqx/Phishing-Email-Analysis-Report/blob/main/Main-Report]), covering:
